# AGENTS.md

Utilitários de gestão de projetos com Google Sheets como base de dados oficial (não é git; sem CI/lint). Todo o conteúdo e as respostas são em **português (pt-BR)**.

## Arquivos

- `app.py` — app Streamlit único: **8 páginas** na barra lateral (dispatch por `MAPEIO` com nomes literais), fonte Google Sheets com fallback **por aba** para CSV local; tema com **6 paletas** (`TEMAS`, CSS próprio parametrizado — `config.toml` só vale na 1ª carga) atrás do ícone **🎨 `st.popover`** no topo da lateral; helpers `cabecalho()`/`estilizar_fig()`. Dashboard tem **2 abas** (`st.tabs`: **🌍 Visão Geral** com KPIs+curva S+**indicadores novos** — `indicadores_visao_geral()`: marcos atrasados da Timeline, frentes paradas com prazo ≤45 d, físico × financeiro por contrato com desvio >10 p.p. — e **📅 Por Cronograma** com `secao_cronograma_rapido()`: Gantt + `st.data_editor` de `%_Concluido` (num_rows dynamic; ✕ marca exclusão) aplicado via `aplicar_avancos(dados, avancos, excluidas)` em `session_state["cronograma_importado"]`, com confirmação e bump de `versao_avancos` na key), **filtro por Contrato** (vincula tarefa→contrato via coluna `Contrato` do cronograma ou mapa Frente→Projeto da `Timeline_Visao`; recorta tarefas/RH/contratos — alertas ficam do projeto inteiro) e **drill-down nos KPIs** (`st.popover` + `_tabela_tarefas`/`_drill_tarefas`). Assinatura “por Jozemir Leite” no cabeçalho (classe `.pag-ass`). **Importar/Exportar é um wizard**: pergunta Nome do projeto (coluna extra `Projeto_Nome`), Contrato (seletor com **“➕ Novo contrato...”** → `incluir_contrato()`), **Frente** (reescreve o 1º nível do WBS; “➕ Nova frente...”), **Responsável** (só células vazias; “➕ Novo responsável...”), **checkbox vínculo Timeline** (cria linhas Frente→Projeto via `acrescentar_aba()`) e modo **Acrescentar (incluir no grupo)** × Substituir — acrescentar usa `acrescentar_cronograma()`/`acrescentar_aba()` que concatenam com a base efetiva e **renumera a coluna-chave** (`CHAVES_ABA`; coluna de vínculo por aba em `COLUNA_CONTRATO` — histograma usa `Contrato_Vinculado`); histograma pergunta o contrato e grava antes de `validar_aba`; export nomeia os arquivos com o slug do projeto. Página Contratos: expander **➕ Cadastrar novo contrato**, abas **📎 Vincular cronograma/histograma** (`_vincular_*`) e expander **🗑️ Excluir contrato** (`excluir_contrato()` remove o ID e limpa `Contrato`/`Contrato_Vinculado`/marcos da Timeline, com aviso de impacto + checkbox de confirmação). **Fluxo único de gravação**: toda mutação de base (avanços/exclusões do Dashboard, cadastros/vínculos/exclusão de contrato, imports do wizard) grava em `session_state["{chave}_importado"]` e é lida por **todas** as páginas via `aba_efetiva(dados, chave)` (as 4 páginas de leitura NUNCA leem `dados.get(...)` direto — senão a exclusão não propaga). O botão **💾 Salvar tudo na fonte** na sidebar (expander que só aparece com `{chave}_importado` pendente) chama `salvar_tudo_na_fonte(dados, fonte, id_planilha, api_url, api_key)`: itera as abas alteradas, grava cada uma via `salvar_aba(...)` (reusa o diff por coluna-chave da API), limpa `{chave}_importado`/`_nome` em sucesso e bumpa `versao_avancos`; erros ficam na sidebar sem limpar a session (retry possível). **Página 📝 Relatório (IA)**: `config_ia()` lê `[ia]` do secrets (API compatível com OpenAI — base_url/model/api_key; `st.secrets` sem arquivo lança → try/except), `resumo_dados()`/`bloco_resumo()` montam o digest numérico (**inclui marcos atrasados, frentes paradas e físico × financeiro por contrato**), `gerar_relatorio_ia()` chama `/chat/completions` via `requests` e `relatorio_local()` gera o mesmo relatório sem chave (nunca falha em branco). `fig_gantt()` é o helper único do Gantt (Timeline e aba Por Cronograma).
- `static/` — arquivos do **PWA**: `manifest.json`, `sw.js`, `icon-192/512.png`. Servidos em **`/app/static/`** (NÃO `/static/`) e exigem `server.enableStaticServing = true` no config.toml (reiniciar para valer). O `<head>` do Streamlit é montado pelo React e não aceita manifest via config: injeta-se via `st.components.v1.html` (iframe tem `allow-same-origin`+`allow-scripts` → alcança `window.parent.document`) em `injetar_pwa()`. A mesma injeção cria o **bloco `#pwa-bloco` no fim da árvore lateral** (`stSidebarContent`, com polling 500 ms até o sidebar existir; sobrevive aos reruns — se o React limpar, o próximo run recria): botões **📲 Instalar** (painel com passo a passo por plataforma + “Instalar agora” quando o pai captura `beforeinstallprompt` — listener sempre no pai, nunca no iframe) e **🔗 Compartilhar** (`navigator.share` → fallback `clipboard.writeText` → `execCommand`, com feedback “Copiado ✓” no `#pwa-share-txt`). `URL_APK` (constante acima da função): preenchida, o painel ganha o link “⬇ Baixar .apk”.
- `gerar_icones_pwa.py` — regenera os ícones (só PIL).
- `.streamlit/config.toml` — tema escuro/headless/sem telemetria; lido **só na inicialização** do servidor (reiniciar para valer).
- `conversor-cronograma.py` — CLI só stdlib que converte o padrão `DB_Cronograma_MSProject` ⇄ MS Project/P6. O app o reusa via `importlib` (nome tem hífen — não existe `import conversor-cronograma`).
- `streamlit_app.py` — shim de entry point que só faz `from app import main` + `main()`. É o arquivo que o **Streamlit Community Cloud** procura por padrão na raiz do repositório; `app.py` resolve tudo por `Path(__file__).parent`, então o shim na mesma pasta funciona sem ajuste. Testado: `python -m streamlit run streamlit_app.py` sobe e renderiza (0 `stException`). Local pode continuar usando `streamlit run app.py`.
- `leitor_mpp.py` — leitor puro Python de `.mpp` MPP14+ (2010 em diante), só com `olefile` (sem Java/COM — funciona na nuvem). API: `interpretar_mpp(bytes) -> (DataFrame 15 colunas, avisos)`. Layout decifrado empíricamente contra `.mpp` real + export Excel (ver "Armadilhas"). Import lazy no `app.py` (só carrega com upload de `.mpp`).
- `data/exemplos/*.csv` — as 6 abas de exemplo (separador `;`, UTF-8 com BOM, datas DD/MM/AAAA), ancoradas em set–dez/2026; os alertas assumem "hoje" ≈ out/2026.
- `iniciar_app.bat` — launcher desktop (ASCII puro, sem BOM): sobe o Streamlit em janela minimizada e abre o navegador via health-check PowerShell. NÃO acrescentar acentos no arquivo (cmd lê em OEM).
- `.gitignore` — protege `.streamlit/secrets.toml`, credenciais, `__pycache__`, `AGENTS.md` e `gestao-projetos*.md` (docs internas) de subir para o GitHub.
- `gestao-projetos (1).md` — **prompt de agente, não documentação do código** (frontmatter `agent: plan`, placeholders `$ARGUMENTS`). Fonte das regras de trabalho e do layout das abas. O nome tem espaço e `(1)`: cite o caminho entre aspas no shell.
- `README.md` — como rodar, secrets do Sheets e convenções de dados.

## Arquitetura (não dá para adivinhar)

- **Frente = 1º nível do WBS** (`FUND.20` → frente `FUND`). Vínculo tarefa→contrato: coluna extra `Contrato` se existir no cronograma; senão mapa Frente→Projeto da `Timeline_Visao` (coluna `Projeto` recebe o `ID_Contrato`).
- Cada aba do Sheets cai sozinha para o CSV local quando falha (credenciais em `.streamlit/secrets.toml` → `[gcp_service_account]`); o app nunca falha em branco — só avisa no topo.
- Upload aplicado fica em `st.session_state["cronograma_importado"]` e vale para todas as páginas; botão na barra lateral restaura a origem.
- Importação: CSV/XLSX com cabeçalho `ID_Tarefa...` entra direto e **preserva Status**; cabeçalho MS Project/P6 passa pelo conversor (Status é derivado de `%_Concluido`); XML do MS Project é lido por `interpretar_msproject_xml`; `.mpp` MPP14+ por `leitor_mpp.interpretar_mpp` (import lazy; versões antigas → `ValueError` amigável que vira `st.error`). `.xer` não é suportado.

## Armadilhas verificadas

- `px.timeline` **já inverte o eixo Y** (1ª tarefa no topo): não acrescente `autorange="reversed"` — o Gantt sai de cabeça para baixo (dobra a inversão).
- `pd.to_datetime(..., dayfirst=True)` **deforma datas ISO** (`2026-09-01` vira `2026-01-09`); use `parse_datas()` (tem ramo ISO explícito) em vez do pandas direto.
- Conversor: delimitador de **entrada** é auto-detectado (`;` vs `,`), **saída** é fixa — `;` para MS Project/Sheets e `,` para P6. Lê e grava tudo com `utf-8-sig` (BOM); preserve.
- **Binário `.mpp` (leitor_mpp.py) — layout decifrado, não inventar offsets:** stream `TBkndTask/FixedData` = **header 48 B** + registros de **202 B** (48 + 923×202 = 186.494, resto 0 no arquivo de teste); por registro: **ID sequencial em @0** (ordem de exibição do MS Project), **UID em @4**, **is_summary (u8) em @140**. Header 52 desloca tudo 4 B e perde a última tarefa. Streams raiz: diretório `   114*` (raiz ausente = MPP antigo → recusar). VarMeta: itens de 12 B (uid, offset Var2Data, campo4) a partir de @24, n_itens em @8; `campo4` tem forma `0x0B4000NN` — validados: 14=Nome (UTF-16LE), 27=Duração (décimos de min; 5400 = 9h/dia), 43=Start, 44=Finish (u32, época 31/12/1983, /65536 dias), 87=%_Concluido (f64).
- **WBS do `.mpp` não vem pronto:** o "outline level" não existe como campo simples (o marcador u16 `0x0B4000B3` = 21 resumo / 7 / 5 NÃO é profundidade — aparece em WBS de 2 e 3 componentes). Reconstruir por **contenção de datas** em pré-ordem (ordenar por ID @0) + pilha de resumos: um resumo fecha quando a próxima tarefa não cabe em [início, fim] (rolamento do MS Project garante que filho sempre cabe no resumo). Raiz fica sem segmento WBS (convenção MS Project; `validar_cronograma` não reclama). Validado 43/43 resumos com rolamento exato + 11/11 linhas do export Excel.
- `.mpp` não binário: `Responsavel` (vínculo alocação↔recurso usa índices internos não decifrados — nunca inventar), `Caminho_Critico` (marcado `NAO` + aviso) e datas reais (derivadas do `%_Concluido`) — sempre avisar na página.
- Datas sempre DD/MM/AAAA na saída; em ambíguas (`05/06/...`) vale dia/mês.
- **Round-trip perde `Status`:** export MS Project concatena `Status | Observacao` em Notes; export P6 nem tem a coluna. Nunca confie no Status após um ciclo export/import no formato estrangeiro.
- Export MS Project: `Duration` vira `5 dias`, `Critical` SIM/NAO → Yes/No; o import mapeia cabeçalhos case-insensitive e aceita inglês (MS Project) ou P6.
- **`StreamlitDuplicateElementId` invisível na suíte bare:** widgets do MESMO run com mesmo `label`+`options` colidem (ex.: `selectbox "Contrato"` nas abas MO e Equip — as duas rodam no mesmo run de `pagina_histograma`). O teste bare não registra IDs (sem script-ctx) e o erro só aparece como `stException` **na página** + no log do servidor. Regra: todo widget das abas MO/Equip tem `key=` único (`hist_mo_*`/`hist_equip_*`); `_grafico_previsto_real` recebe `chave` porque `st.plotly_chart` sempre registra ID. Registros: `container` só registra com `key`; `columns`, `metric` e `dataframe` sem seleção **não** registram; `tabs`/`expander`/`plotly_chart` sempre.
- Plotly **corta** (não expande) texto fora da margem — SVG tem `overflow:hidden`: Gantt usa margem esquerda calculada (`len(maior tarefa)*7.2+16`, cap 500) senão os nomes das tarefas somem; eixos X precisam `b ≥ 34` senão as datas somem. Legenda padrão encosta na borda direita: ancorar (`x=0.99, xanchor="right"`) ou `orientation="h", y=1.12`.
- CSS do tema escuro: seletores por `data-testid` **do Streamlit 1.66** (verificados no DOM real): `stRadioOption[data-selected]`, `stSelectbox input[role=combobox]`, `stMetric`, `stAlertContainer`+`stAlertContent{Error,Warning,Info,Success}`, `stTab`+`.react-aria-SelectionIndicator`, `stProgressBarTrack`, `stFileUploaderDropzone`, `stExpander details`, `stTextInputField`, cards = `stLayoutWrapper > stVerticalBlock` (só casam com containers bordados). Gráficos exigem `theme=None`, senão o tema do Streamlit sobrescreve o custom.
- **Cor fixa do config.toml no `.stApp`/`stHeader`:** o Streamlit pinta `html, body, .stApp` (e cabeçalho) com `backgroundColor`/`textColor` do `config.toml`, fixos desde a 1ª carga — trocar a paleta em runtime deixava tema claro com texto escuro sobre fundo escuro. Corrigido com `background: var(--fundo) !important` em `html, body, .stApp` e `[data-testid="stHeader"], [data-testid="stToolbar"]`.
- **`color-mix(in srgb, var(--acento) X%, transparent)`:** usado nos hovers do tema; funciona nos navegadores atuais, mas se alvo for browser muito antigo o hover fica sem fundo (só a cor).
- **Selecionar opção de `st.selectbox`/combobox via JS:** o gatilho é o `button` dentro de `.react-aria-ComboBox` (não o `input`); o popup renderiza `[role="option"]` e fecha se houver clique/avaliação intermediária — abrir e clicar no mesmo `evaluate`, ou policiar rápido. `browser.evaluate` não tem `setTimeout`; usar laço de chamadas.
- **Drill-down dos KPIs:** `st.popover` (existe no 1.66); o gatilho pequeno é estilizado por `[data-testid="stPopover"] > button`. O grid `st.dataframe` desenha em canvas (glide) — o texto das células NÃO aparece em `innerText`; validar por screenshot ou pela presença de `[data-testid="stDataFrame"]` com altura.
- **Estado do template:** o seletor `Template do Dashboard` fica na barra lateral (kwarg `template` no dispatch das páginas via `MAPEIO`). `st.session_state["template_dash"]` persiste na sessão — após reload que reatacha, o valor antigo volta (comportamento esperado do Streamlit).
- **`beforeinstallprompt` não dispara no navegador de teste do OpenCode** (UA custom `OpenCode/...`): validar o botão 📲 pelo DOM (`#pwa-btn`, `#pwa-painel` com o texto por plataforma) e não exigir `window.__pwaPrompt` — o "Instalar agora" só aparece em Chrome/Edge de verdade. Em iOS nunca dispara (só instrução Safari).
- **Expressão ternária solta no fim do script vira "None" na tela:** a "mágica" do Streamlit renderiza expressões que não são `Call` (ex.: `MAPEIO[p](d, template=t) if x else MAPEIO[p](d)` — `IfExp` no AST) e o retorno `None` aparece como `<code>None</code>` no fim do fluxo principal. Sempre `if/else` de verdade para dispatch de página.
- **Pandas com dtype Arrow (string) rejeita gravar float na coluna:** `df.loc[m, "%_Concluido"] = floats` lança `TypeError: Invalid value for dtype 'str'`. Converter a coluna antes: `df[col] = pd.to_numeric(df[col], errors="coerce").fillna(0.0)` e só então atribuir.
- **Canvas do `st.data_editor` (glide) ignora eventos sintéticos:** `dispatchEvent` de Mouse/Keyboard não edita célula (exige `isTrusted`); e não existe tool de digitação real no browser de teste. Validar a lógica de edição pela suíte Python (chamar a função de aplicação com dicts simulados) e no browser só a renderização (grid + botões). `st.text_input` commita com **Enter** (evento `keydown` keyCode 13 após o setter nativo + `input`) — sem isso o botão dependente do valor fica `disabled`.
- Verificação em navegador: checar **`stException` na página** (erro de script não vai ao console) e o log do servidor. Atenção: `text-transform: uppercase` nos rótulos KPI ⇒ procurar por "TOTAL PREVISTO" (não "Total previsto"); editar `app.py` com servidor aberto mostra o banner "File change → Rerun" (clicar nele ou reload total; reload = sessão nova, volta ao Dashboard); medição durante o render progressivo dá falso positivo — aguardar o texto do último elemento.
